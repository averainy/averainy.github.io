    如何修复wsus客户端长时间不报告状态

    可以使用以下脚本尝试恢复wsus客户端长期不报告状态的故障:

    
# 1. 停止Windows Update服务
net stop wuauserv

# 2. 清除下载缓存和临时文件
del /f /s /q %windir%\SoftwareDistribution\*.*

# 3. 重新启动服务
net start wuauserv

# 4. 强制联系WSUS服务器并报告状态
wuauclt /resetauthorization /detectnow
wuauclt /reportnow
